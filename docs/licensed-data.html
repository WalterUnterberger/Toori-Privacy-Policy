Overview

This page documents externally licensed datasets used by Toori and provides attribution, licensing details, modification notes, and public access where required.

Toori uses Japanese language data derived from third-party linguistic datasets. Such data remains subject to the license terms of the original providers.

Some databases distributed by Toori contain adapted data licensed under Creative Commons Attribution-ShareAlike 4.0 International. Those adapted databases are made publicly available under the same license.

JMdict / JMdictDB

Japanese Dictionary Data

Japanese dictionary data used in Toori is derived from JMdict, provided by the Electronic Dictionary Research and Development Group (EDRDG).

  • Dataset: JMdict / JMdictDB
  • Provider: Electronic Dictionary Research and Development Group
  • License: Creative Commons Attribution-ShareAlike 4.0 International
  • Copyright: Electronic Dictionary Research and Development Group

Original source: EDRDG

License details: EDRDG License Page

Modifications

  • Parsed and converted source data into SQLite database format
  • Normalized data structures for application use
  • Added internal identifiers
  • Added source provenance metadata
  • Added Toori-specific indexing and application metadata

KANJIDIC2

Kanji Data

Kanji data used in Toori is derived from KANJIDIC2, provided by the Electronic Dictionary Research and Development Group (EDRDG).

  • Dataset: KANJIDIC2
  • Provider: Electronic Dictionary Research and Development Group
  • License: Creative Commons Attribution-ShareAlike 4.0 International
  • Copyright: Electronic Dictionary Research and Development Group

Original source: KANJIDIC Project

License details: EDRDG License Page

Modifications

  • Parsed and converted source data into SQLite database format
  • Normalized kanji, reading, and meaning records
  • Added internal identifiers
  • Added source provenance metadata
  • Added Toori-specific classification and indexing metadata
